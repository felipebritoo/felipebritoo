## 💜 Sobre mim

Sou estudante de **Engenharia da Computação** na Facens, com um forte direcionamento para a área de **Engenharia de Software** e arquitetura de sistemas. 

Meu foco principal é construir aplicações robustas, seguras e escaláveis. Para isso, mergulho fundo no ecossistema backend e busco sempre aplicar as melhores práticas de desenvolvimento e padrões de projeto.

- 🔭 **Atualmente focado em:** Desenvolvimento backend com **Java** e **Spring Boot**, construindo APIs eficientes, e criando arquiteturas modernas.
- 🌱 **Estudando no momento:** Engenharia de Software, testes de software, **Angular** para frontend e integrações de ferramentas.
- 💬 **Fale comigo sobre:** Estruturação de projetos em Spring Boot, metodologias ágeis, C/C++ ou análise de dados!
